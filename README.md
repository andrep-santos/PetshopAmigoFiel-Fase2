## 🚀 Funcionalidades Implementadas

Atendendo aos requisitos da Fase 2, foram adicionados os seguintes recursos:

### 📱 Interface Responsiva (Bootstrap 5)
- Implementação de layout responsivo utilizando o sistema de grid do **Bootstrap 5**, garantindo compatibilidade entre dispositivos móveis e desktops.
- **Navbar:** Menu de navegação adaptável (hambúrguer em mobile).
- Organização visual dos serviços através de Cards responsivos.

### ✨ Interatividade e Dinamismo (JavaScript)
- **Carrossel de Imagens:** Banner rotativo na página inicial destacando os diferenciais do Petshop.
- **Função Temporal:** Exibição de uma mensagem de saudação personalizada na página de cadastro (*"Bom dia"*, *"Boa tarde"* ou *"Boa noite"*), calculada automaticamente com base no horário do sistema do usuário.

### 📝 Formulário de Cadastro e Agendamento
- Coleta de dados do tutor (Nome, CPF, Endereço, Contato) e do Pet (Nome, Raça, Idade).
- Seleção dinâmica de serviços (Banho, Tosa) e método de transporte.
- **Validação Client-side:** Lógica em JavaScript que impede o envio de formulários incompletos e exibe alertas de confirmação para o usuário.

### ♿ Acessibilidade
- Uso de atributos `alt` em todas as imagens para suporte a leitores de tela.
- Estrutura semântica correta (`<nav>`, `<section>`, `<footer>`) para facilitar a navegação por teclado e tecnologias assistivas.
